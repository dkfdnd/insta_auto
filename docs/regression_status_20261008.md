편집 테스트는 설치된 FFmpeg bin을 테스트 프로세스 PATH에 추가해 확인했다. 음성 기본 설정, 서버 프로세스 및 운영 DB를 변경하거나 재시작하지 않았다. `auto_capcut`의 기존 자막 테스트 하나는 사용자가 승인한 쉼표·온점 제거 규칙에 맞춰 기대값을 갱신했다. 폰트 라이선스 파일은 upstream 원본의 공백까지 그대로 보존했다.

## 남아 있는 insta_auto 실패

- `test_dashboard_browser.py`: 알림 도움말 열림 상태 1개, 상세페이지 성과 영역 표시 2개.
- `test_priority_improvements.py`: 이전 후보 캐시 선택, 비영상 URL의 거절 사유 각 1개.
- `test_production_flow_browser.py`: 9개. 대본 입력창 셀렉터가 두 요소에 매칭되는 문제, 숨겨진 재검색/소스 선택 컨트롤, 수정 전 음성 표시 및 편집·저장 흐름의 기대와 실제 DOM 차이를 확인했다.
- `test_source_strategy_browser.py`: 실행 중 검색 전략 표시 1개.
- `test_studio.py`: 과거 작업 실패가 새 대본 상태에 미치는 영향 검사 1개.

이들은 실행 로그에서 관측한 실패다. 변경된 UX와 구형 테스트 기대의 불일치인지 실제 기능 회귀인지는 개별로 재현하고 판단해야 한다. 검사를 건너뛰거나 기대값을 일괄 완화하지 않았다.

## 공개 파일 범위

네 저장소의 코드·문서·테스트·폰트 및 기존 효과음 자산을 포함했다. Git 제외 대상인 영상 제작 결과, DB, 로그인 쿠키/세션, 모델, 참조 음성, 로컬 실행 기록은 포함하지 않았다. 변경 파일의 문자열 검사에서 발견된 자격 증명 형태의 값은 임시 테스트 서버용 고정 fixture 한 개였고 실제 운영 비밀값은 발견되지 않았다. 이 검사는 모든 종류의 비밀값을 보증하는 검사는 아니다.
