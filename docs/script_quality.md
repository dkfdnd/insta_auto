# 제작실 대본 표현 검사

제작실의 대본 입력란 옆 **현재 문장 검사**를 누르면 현재 입력한 문장을 script_auto에 보내 표현·말끝·원본 겹침 참고 결과를 받는다. 저장 전 문장도 검사할 수 있고 검사만으로 저장·승인·TTS가 실행되지는 않는다. 새 제작 흐름과 기존 단계별 제작실에 동일하게 제공한다.

검사 중 문장을 바꾸면 이전 응답은 적용하지 않으며, 입력을 수정하거나 임시 입력을 다시 불러오면 재검사를 안내한다. 원본 발화가 없는 수동 제작 작업에는 원본 부족 안내가 함께 나올 수 있다. 표현 지적이 없다는 것과 원본 차별성·사실 확인은 별개다.

규칙 소유자는 script_auto다. `StudioAdapter.review()`는 인증된 `POST /api/scripts/review`를 호출하며 10초 제한을 적용한다. 모델 실행과 외부 사이트 호출이 없는 검사다. script_auto가 중지돼 있거나 구버전이면 연결 실패를 표시하고 입력문은 보존한다. 검사 요청은 제작 상태나 이력을 변경하지 않는다.

자동 생성 단계에서 script_auto가 의미 변경 의심으로 보류한 후보는 기존 `rewrite_review.status` 계약에 따라 자동 선택에서 제외된다. 검사 버튼은 이 보류를 해제하지 않는다. 상세 보류안과 초안은 script_auto 결과 화면에서 비교한다.
