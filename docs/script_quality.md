# 대본 검사

제작실의 **현재 문장 검사**는 입력한 원고를 내장 `writing/checks.py`로 검사한다. 외부 서버·모델 호출이 없고 입력문을 수정하거나 저장하지 않는다. 문구 겹침·의미 강화·원본에 없는 사연 추가·수치·말투는 참고 의견이다. 원본의 경험담 설정과 1인칭 재작성은 허용하며, 문장 복사는 별도로 검사한다.

규칙 원본은 `hotpost/writing/RULES.md`이며 집필과 자동 검사 흐름은 [내장 집필 안내](writing.md)를 따른다. 내용 의견으로 제작을 보류하지 않는다. 대본·원본 해시가 다르거나 응답이 손상된 경우는 기술 오류로 구분한다.
