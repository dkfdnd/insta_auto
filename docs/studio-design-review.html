제작에 집중하는
유리 질감의 작업 공간

사용자가 제공한 3개 레퍼런스의 부드러운 입체감, 반투명 재질, 밝은 여백을 제작실에 적용했습니다. 단순한 색상 교체와 함께 원본 발화 확인을 독립 단계로 분리하고, 쓰기·비교·듣기·검토의 배치를 다시 정리했습니다.

근거를 어떻게 적용했나

아래 배치는 이 프로젝트에 대한 설계 판단입니다. 사용성 원칙을 근거로 검토하고 브라우저로 동작을 검증했지만, 사용자 실험으로 작업 시간이나 오류 감소를 입증한 결과는 아닙니다.

  • NN/g 사용성 휴리스틱: 상태를 보이게 하고, 사용자의 언어로 행동을 설명하며, 되돌릴 방법을 제공합니다. 이에 따라 보는 단계와 실행 상태를 구분하고 저장/재제작/다운로드를 다른 행동으로 표현했습니다.
  • NN/g 점진적 공개: 자주 쓰는 기능을 먼저, 고급 기능을 필요할 때 노출합니다. 발음 교정, 자막 타이밍, 과거 버전, AI 구간 요청을 접기 영역에 배치했습니다. 단계 간 왕복은 막지 않습니다.
  • W3C 글자 명암 대비: 일반 글자 최소 4.5:1을 설계 기준으로 참고했습니다. 유리 재질은 탐색 영역에 집중하고 입력 배경은 불투명하게 했습니다. 흰 글자/파란 그라데이션의 가장 밝은 색 4.80:1, 흰 글자/주황 그라데이션의 가장 밝은 색 5.25:1, 보조 글자 #54647c/흰 배경 6.02:1을 계산했습니다. 전체 WCAG 적합성 인증을 의미하지 않습니다.
  • W3C 클릭 대상 크기: AA의 최소 기준은 예외 조건을 포함한 24×24 CSS px입니다. 이 화면의 주요 버튼 높이는 편안한 조작을 위해 44px 이상으로 설계했습니다. 체크박스는 큰 라벨 행과 함께 클릭합니다.

시각 규칙: 흰 작업 면 + 옅은 청색·보라빛 배경 / 파란색 주요 조작 / 주황색 최종 영상 저장 / 입력란의 얕은 내부 그림자 / 카드의 빛나는 상단 경계 / 눌렀을 때 1px 이동 / 움직임 줄이기 설정 지원.

STEP 01

소스 영상

추가할 영상과 사용할 영상을 한 흐름에서 결정합니다. 업로드는 위에, 선택한 영상은 바로 아래에 두어 추가 후 결과를 확인할 수 있게 했습니다.

버튼·조작배치 이유와 동작
영상 여러 개 선택업로드 영역 오른쪽의 파란 버튼. 파일을 직접 골라 넣는 가장 흔한 시작 동작입니다. 드래그가 어려운 사용자도 같은 작업을 할 수 있습니다.
드래그 앤 드롭점선 영역 전체를 드롭 대상으로 사용합니다. 파일 형식·크기 제한을 같은 영역에서 먼저 알려 시행착오를 줄입니다.
업로드 재시도실패한 파일 옆에만 나타납니다. 성공한 파일까지 다시 올리지 않고 해당 파일만 처리합니다.
전체 선택 / 선택 해제영상 목록 바로 위에 보조 버튼으로 묶었습니다. 저장 버튼과 외형을 구분해 선택과 확정을 혼동하지 않게 합니다.
영상별 체크박스썸네일 아래 파일명과 함께 클릭합니다. 선택 카드의 파란 테두리와 체크 표시를 같이 사용해 색만으로 상태를 전달하지 않습니다.
영상 재생 / 영상 다운로드각 카드 안에서 먼저 확인하고 필요하면 개별 파일을 받습니다. 체크하는 행위와 재생하는 행위를 분리했습니다.
소스 선택 저장목록 아래에 두어 선택을 마친 후 확정합니다. 이미 만든 작업에서는 저장 후 하단 재제작으로 반영합니다.
선택한 영상으로 제작 이어가기자료 준비 중인 작업에서는 저장 대신 이 버튼을 제공합니다. 선택 영상이 없거나 준비 작업이 실행 중이면 비활성화됩니다.
자동 소스 검색 / 소스 검색 시작직접 업로드 다음의 접힌 보조 기능입니다. 요청 내용을 작성하고 명시적으로 검색을 시작합니다. 외부 검색 속도 제한은 유지합니다.

STEP 02

원본 발화

원본 영상과 교정문을 나란히 배치했습니다. 듣기와 수정의 왕복 거리를 줄이고, 원본 발화와 새 제작 대본을 별도 단계로 구분했습니다.

버튼·조작배치 이유와 동작
원본 영상 재생·탐색·음량교정문 왼쪽에 고정된 비교 자료입니다. 익숙한 브라우저 기본 플레이어를 사용합니다.
시간별 자동 인식 발화긴 전사 기록은 접어 둡니다. 필요한 구간을 찾을 때만 펼칩니다.
시간 표시 ▷해당 발화 시간으로 원본 플레이어를 이동합니다. 문장을 기억한 채 영상 전체를 다시 탐색할 필요를 줄입니다.
원본 발화 교정본 입력영상 옆의 넓은 불투명 입력란에서 편집합니다. OCR 문구와 섞지 않고 실제 들리는 말만 기록합니다.
발화 교정본 저장교정문 바로 아래의 주요 버튼입니다. 원본 자동 인식 기록은 보존하며, 제작 대본·현재 음성을 자동 교체하지 않습니다.
자동 인식 원문 · 보존됨교정 전 기록이 필요할 때 펼칩니다. 수정한 문장과 자동 인식 문장을 비교할 수 있습니다.
화면 속 글자OCR이 있는 작업에서 별도 접기 항목으로 표시합니다. 화면의 광고 문구를 실제 발화라고 착각하지 않게 분리합니다.
STEP 03

제작 대본

왼쪽은 직접 작성하는 넓은 공간, 오른쪽은 AI 수정 도구입니다. 사용자가 작성한 대본을 중심에 두고, AI는 비교한 후 선택하는 보조 도구로 배치했습니다.

버튼·조작배치 이유와 동작
제작에 사용할 대본최대 3,000자 입력란. 17px 본문과 넉넉한 줄 간격을 적용했습니다. 단계 이동 중 저장하지 않은 입력을 유지합니다.
대본 저장입력란 바로 아래의 파란 버튼입니다. 작성한 내용을 확정하지만 음성·완성본 재생성은 하단 버튼으로 별도 실행합니다.
문장 검사저장 옆의 밝은 보조 버튼입니다. 현재 문장을 검사하며 사용자가 작성한 문장을 자동으로 덮어쓰지 않습니다.
문장 검사 결과검사 결과를 확인하는 접기 항목입니다. 오류가 없다는 결과를 사실 검증이나 최종 품질 보장으로 표현하지 않습니다.
AI에게 수정 요청 / 수정안 만들기오른쪽 패널 안에 입력과 실행 버튼을 붙였습니다. 실행 상태와 준비된 수정안도 같은 영역에 나타납니다.
수정안 펼치기 / 이 수정안 선택요청 당시 대본과 제안문을 나란히 비교한 후 선택합니다. 제안이 생성됐다는 이유만으로 즉시 적용하지 않습니다.
이전 제작 대본 복원 / 이 대본을 수정본으로 가져오기버전 기록은 접어 둡니다. 복원 문구가 다음 제작에 사용할 수정본을 가져오는 행동임을 설명합니다.
원본 · 후보 대본 비교 / 이 대본 선택후보 탐색은 하단에 둡니다. 직접 작성보다 빈도가 낮은 선택지를 분리하고 내용 확인 후 선택하게 합니다.

STEP 04

음성

먼저 들어보고, 그다음 속도와 발음을 조절하도록 위아래로 배치했습니다. 현재 들리는 음성과 다음 제작에 적용할 설정을 구분합니다.

버튼·조작배치 이유와 동작
음성 재생·일시정지·탐색·음량넓은 오디오 카드의 핵심 조작입니다. 실제 파일의 재생 시간을 볼 수 있습니다.
이 음성이 읽는 대본현재 음성에 연결된 대본을 펼쳐 확인합니다. 최신 입력문과 과거 음성이 다를 때 원인을 추적할 수 있습니다.
읽는 속도0.80~1.25배를 숫자로 조절합니다. 범위와 실제 값을 확인할 수 있는 기존 입력 동작을 유지했습니다.
발음 교정어려운 단어가 있을 때만 펼칩니다. 원문=발음 예시와 자막은 바뀌지 않는다는 설명을 같은 위치에 둡니다.
음성 설정 저장속도·발음을 정한 뒤 누르는 주요 버튼입니다. 현재 음성을 곧바로 교체하는 동작과 분리했습니다.
음성 다시 만들기 예약같은 대본으로 음성을 새로 생성하고 싶을 때 사용하는 보조 버튼입니다. 실제 반영은 하단 재제작으로 이어집니다.
대본 확인하기음성이 없는 상태에서 제공하는 다음 행동입니다. 빈 플레이어를 보여주는 대신 필요한 이전 단계로 이동합니다.

STEP 05

장면 · 자막

왼쪽에는 영상 미리보기, 오른쪽에는 시간순 구간 카드를 두었습니다. 어떤 부분을 수정하는지 영상과 대조할 수 있고, 데스크톱에서는 미리보기가 스크롤을 따라옵니다.

버튼·조작배치 이유와 동작
미리보기 재생·탐색·음량현재 편집본을 확인합니다. 저장한 변경은 재제작 후 보인다는 설명을 플레이어 바로 아래에 둡니다.
CapCut에서 직접 편집플레이어 아래 보조 버튼입니다. 웹에서 제공하는 조정보다 세밀한 편집이 필요할 때 별도 프로그램을 엽니다.
▷ 시작–끝 시간각 구간 카드의 첫 버튼입니다. 클릭하면 해당 시점으로 이동하므로 수정 대상과 화면을 연결할 수 있습니다.
장면 선택 이유 / 장면 후보 영상 보기판단 근거와 후보 미리보기는 필요할 때 펼칩니다. 자막 수정 동작을 가리지 않습니다.
장면 선택현재 선택한 장면을 보여주는 드롭다운입니다. 같은 구간의 대사와 인접 배치해 대응 관계를 확인합니다.
자막 입력장면 선택 아래에 둡니다. 자막 수정은 음성을 바꾸지 않는다는 설명을 화면 상단에 표시합니다.
자막 타이밍 · 강조 설정자주 바꾸지 않는 세부 설정을 접습니다. 시작·끝 시간을 개별 숫자로 입력하고 강조를 없음/분명하게/강하게 중 고릅니다.
이 구간 피드백 저장각 카드의 마지막에 둡니다. 어느 구간에 저장하는지 범위를 명시하고 전체 재제작과 구분합니다.
AI에게 구간 수정 요청 / 수정안 준비오른쪽 상단의 보조 기능입니다. 요청과 시작·끝 범위를 먼저 지정한 후 실행하게 합니다.
음성 준비 상태 보기편집본이 아직 없을 때 선행 단계로 안내하는 복구 동선입니다.

STEP 06

완성 · 다운로드

영상과 세 가지 검토 항목을 나란히, 파일 받기는 그 아래 별도 영역에 배치했습니다. 재생→확인→저장의 흐름을 만들고, 단계 상태와 다운로드 버튼을 구분했습니다.

버튼·조작배치 이유와 동작
제작 결과 버전 선택상단 오른쪽에서 V18/V19 등 이전 결과를 선택합니다. 선택한 버전에 따라 영상·검토 기록·제작 자료가 함께 바뀝니다.
완성 영상 재생·탐색·음량·전체화면왼쪽에서 실제 결과를 확인합니다. 생성 완료를 사용자의 품질 검토 완료로 간주하지 않습니다.
대사·발음 / 자막·타이밍 / 장면·전환오른쪽의 넓은 체크 행 3개입니다. 행 전체를 클릭할 수 있고, 색과 체크 표시를 함께 사용합니다.
이 버전 검토 완료체크 항목 아래에 둡니다. 현재 선택한 버전에 대한 사용자 검토를 기록합니다. 체크하지 않은 항목이 있으면 서버 검증으로 완료 처리를 막습니다.
완성 영상 · 영상 저장다운로드의 첫 번째 큰 주황색 카드입니다. 최종 MP4를 받는 행동을 제작 자료보다 크게 강조했습니다.
원본 영상벤치마킹 원본 MP4입니다. 작업에 원본이 없으면 아직 없음으로 표시하고 클릭 링크를 만들지 않습니다.
소스 영상제작 소스 묶음 ZIP입니다. 원본 참고 영상과 편집에 쓰인 영상을 이름으로 구분했습니다.
원본 대본원본에서 추출한 발화 TXT입니다. 제작 대본과 별도의 카드입니다.
제작 대본선택한 결과 버전에 사용한 대본 TXT입니다. 편집 중인 초안과 혼동하지 않도록 설명합니다.
