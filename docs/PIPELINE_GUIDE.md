# 제작 파이프라인 안내

insta_auto가 후보 선정·자료 확보와 내장 Codex 집필을 맡고, VoiceBench가 음성, auto_capcut이 편집을 맡는다.

`start-local.cmd`는 Codex 실행 파일을 확인하고 음성·Hotpost 서비스를 시작한다. script_auto 서버는 시작하지 않는다. 새 PC 준비는 [설치 안내](windows-install.md), 집필 규칙과 작업 큐는 [내장 집필](writing.md)을 따른다. VoiceBench의 기본 목소리와 개인 녹음은 기존 설정을 보존한다.

자동 제작은 원본 대본 확보 → Codex 집필·검사·제한 보완 → 개인 복제 음성 → 확보 소스를 활용한 편집 → 최종 영상 순서다. 소스 수집은 병렬로 진행한다. 완성본은 보존하고 수정은 새 버전에 저장한다. 내용 평가로 중간 승인을 요구하지 않는다. 선택 대본과 음성·자막의 해시는 일치해야 한다.

내장 집필에는 별도 HTTP 포트가 없다. Hotpost는 8775, VoiceBench 기본값은 8765이며 VoiceBench 키는 로컬 파일에서만 읽는다. auto_capcut은 독립 Python 프로세스로 실행한다.

## 매일 자료 확보

`python -m hotpost run --acquire`는 통계 수집 후 **조회수 / 팔로워 수**로
릴스만 선정하고 음성 대본·소스 자료까지 확보한다. 기존 평소 대비 급상승 지표는
모니터링에 유지하며 제작 후보 선정 기준과 구분한다.

초기 기본값은 팔로워 대비 1.8배 이상, 최소 1,000회, 한 번에 새 자료가 필요한 릴스
최대 5개다. 설정의 `acquisition_min_views_per_follower`, `acquisition_min_views`,
`acquisition_daily_limit`로 변경한다. 팔로워 미확인·조회수 누락·오래된 관측은 제외한다.
완료한 자료는 재사용하고 실패한 단계는 다음 실행에서 다시 시도한다.

Windows/macOS에서 `python -m hotpost schedule install`로 매일 7시 자료 확보 작업을
등록할 수 있다. 이번 구현 작업에서는 OS 예약을 설치하지 않았다.
Windows 예약은 PC의 현지 시간(현재 한국 시간)이며 사용자가 로그인한 세션에서 실행한다. PC가 꺼져 있거나
로그아웃 상태이면 정각 실행을 보장하지 않는다. macOS LaunchAgent는 시스템 현지 시간을 사용한다.
실행 상태 확인은 `python -m hotpost schedule status`, 제거는 `schedule uninstall`이다.

## 과거 기록: 2026-09-26 로컬 기능 병합

아래는 당시 기록이며 현재 설치·집필 방식은 위 안내를 따른다.

- 새 통합 경로는 `production.html` / `/api/productions`이며 위의 대본 외부 위임 절차를 따른다.
- 기존 승인형 편집 화면은 `studio.html` / `/api/studio`로 유지한다. 두 제작실의 작업·승인 상태는
  아직 통합하지 않았다. 같은 자료를 두 경로에서 동시에 제작하지 않는다.
- 이전 자동 제작 기록(`state.json`)과 다운로드는 `/api/legacy-productions`로 분리했다.
  자동 제작 감시를 다시 켜지 않으며, 기존 작업 재시도는 승인형 제작실로 연결된다.
- 기존 썸네일·블러 마스크·검토된 장면 계획·무료 내보내기 프로필과 자막 전체 폭 설정을 유지했다.
  이것이 새 통합 화면에서 모든 편집 옵션을 설정할 수 있다는 뜻은 아니다.
- `source_ranges`와 블러 마스크를 함께 전달하면 마스크의 원본 시간 좌표를 잘라낸 영상 좌표로 변환한다.
  검토된 장면 계획이 있으면 원본 해시를 보존하기 위해 미리 자르지 않고, 계획의 모든 샷이 선택 구간 안에 있는지 검사한다.
- Windows 예약 실행의 UTF-8 로그·일시 오류 1회 재시도를 유지하면서 `run --acquire`를 연결했다.
  설치된 작업 설정이나 실행 중인 서버를 이번 병합에서 재시작하지 않았다.

두 제작실을 하나로 합치는 것은 별도 작업이다. 기존 제작실의 내부 대본 생성 경로를
폐기하거나 `script_auto`로 이관하는 결정을 Git 병합만으로 대신하지 않는다.

병합 후 로컬 확인: insta_auto 테스트 166개, auto_capcut 테스트 141개 통과.
VoiceBench의 인증된 `/v1/health`는 200을 반환했다. 반면 script_auto 기본 키 파일은
없었고, 18765 포트의 비인증 `/api/health`는 404를 반환하여 해당 포트의 프로세스를
정상 script_auto 서비스로 확인하지 못했다. 올바른 실행 위치·주소·키를 연결하기 전에는
새 통합 경로의 실제 대본 재가공부터 최종 제작까지 검증 완료로 취급하지 않는다.

## 유지되는 한계

제작실의 **대본·목소리 → 목소리 선택**에서 설치된 Qwen·ZONOS2 공식 목소리를 성별·모델별로 찾고 미리 들을 수 있다. ‘이 목소리 사용’은 다음 제작 설정을 고르며, ‘수정한 영상 만들기’를 누르면 선택한 목소리로 음성과 영상을 다시 만든다. 기존 완료본은 보존된다. ‘내 목소리 · 기존 기본값’을 선택하면 VoiceBench의 기존 기본 설정으로 돌아간다.

목소리 목록과 미리듣기는 Hotpost 서버가 인증된 VoiceBench `/v1/voices` API에서 가져온다. 브라우저에는 API 키를 보내지 않는다. 양쪽 서버에 새 코드가 적용되어 있어야 하며, 모델·샘플 설치는 각 PC에서 별도로 수행한다. 목소리 이름 옆 언어는 공식 음색의 기준 언어이고, ‘한국어 샘플’은 실제 한국어 생성 결과다. ‘공식 참조 녹음’은 한국어 합성 결과와 구별한다.

- 실제 촬영 원본과 자동 전사 정확도는 보장하지 않는다. 소스 출처·품질 메타데이터를 보존한다.
- 원본과 다르게 보이는 정도는 문구 검사와 스타일 변경만으로 확정할 수 없다.
- 생성한 CapCut 초안은 최종 MP4가 아니다. 내보내기 후 PersonalProject1 영상 검사 기능을 별도로 사용할 수 있다.
- 실제 계정·모델·CapCut을 사용하는 한 편의 운영 검증과 테스트용 서비스 연결 검증은 구분한다.

## 수집 결과와 제작실 연결 표시

제작실의 ‘이번 수집이 어떻게 반영됐나요?’는 최신 수집의 새 게시물·새 핫 영상 수와 자동 선정 결과를 구분한다. 자동 선정은 한국 시간 오늘 최초 발견한 핫 영상 전체를 급상승순으로 등록한다. 신규 등록과 기존 작업 연결을 별도로 집계하며 지표 미확인은 경고로 남긴다. 진행 불가는 현재 작업 상태다. 이미 있는 작업은 중복 등록하거나 자동 재시도하지 않는다.

이번 수집에서 처음 발견한 핫 영상은 펼쳐서 직접 선택할 수 있다. ‘이 영상 제작 시작’은 소스 확보부터 자동 제작을 시작한다. 추가 도중 다른 요청이 같은 영상을 먼저 등록했더라도 기존 작업을 재시작하지 않고 연다. `/api/studio/intake` 조회는 제작 작업을 생성하지 않는다. 수집이나 리포트 갱신이 끝나지 않았을 때 이전 선정 결과를 이번 결과로 표시하지 않는다.
