# 오늘 감지된 영상의 우선 제작

한국시간 00:00~24:00에 **처음 핫 기준을 통과했다고 기록된 시점**을 기준으로
오늘 영상과 과거 영상을 나눈다. 업로드 날짜, 첫 수집 날짜, 리포트 재생성 날짜와
혼동하지 않는다. `hot_detections`의 최초 기록은 재수집이나 재평가로 갱신하지 않는다.

메인 상단 집계와 목록의 기간 필터는 모두 이 **발견 시각**을 사용한다.
기본 목록은 ‘오늘’(한국 시간 00시부터)이며, ‘최근 24시간/3일/7일/14일/30일’은
현재 시각에서 해당 시간만큼 거슬러 계산한다. 상단 숫자는 목록 조건과 무관하게
오늘 기준을 유지하므로, 최근 24시간을 선택하면 어제 발견한 게시물도 목록에 포함될 수 있다.
발견 시각이 없는 항목을 업로드 시각이나 첫 수집 시각으로 대신 넣지 않는다.
업로드 시각은 카드의 참고 정보로 구분하며, ‘최근 발견순’도 발견 시각을 사용한다.
이 화면 필터는 수집·판정에 사용하는 분석 대상 범위를 바꾸지 않는다.

- 화면은 오늘 최초 감지 그룹을 먼저 배치하고, 각 그룹 안에서 선택한 정렬을 적용한다.
- 이전 날짜 또는 최초 감지 시점이 없는 과거 핫 영상은 소모 대상으로 표시한다.
  기록·영상·대본·기존 완성본은 보존하며, 제작 완료 상태를 만들어 넣지 않는다.
- 일일 자동 제작은 오늘 최초 감지된 핫 영상 전체를 급상승순으로 등록한다. 최신 조회수 미확인은 안내로 남기며 등록에서 제외하지 않는다. 같은 수집 실행의 선정 기록은 고정하고 중복 작업을 만들지 않는다.
  오늘 대상이 없으면 과거 영상으로 채우지 않는다.
- 자동 선정 영수증은 수집 실행 ID와 한국 날짜, 정책 버전을 묶어 고정한다.
  제작실 수집 연결 화면도 같은 키로 읽는다.
- 전체 영상 선정에는 `finish_selected_batch`를 저장하며, 날짜가 바뀌어도 등록된
  묶음은 완료까지 진행한다. 과거 영상의 목록상 소모 표시는 실행 중 제작을 취소하지 않는다.
  예전 상위 두 편 선정 정책의 중지 기록과 사용자가 직접 중지한 상태는 보존한다.
- 사용자가 명시적으로 요청한 묶음과 수동 제작은 일일 소모 제한에서 제외한다.
  2026-10-04 업로드 12개 요청은 등급과 무관하게 고정한 별도 영수증으로 관리하며,
  우선순위 100으로 과거 자동 작업보다 먼저 수행한다.

소스 유사 기능 허용, 삽입 텍스트의 검토된 블러, 대본의 사실성 검사,
공식 VoiceBench 목소리 및 대본·낭독·자막 일치 검사는 그대로 적용한다.

장면 선택 AI에는 대사와 실제 장면 이미지·시간만 전달한다. 초기 임시 후보
순서를 입력하면 그대로 복사해 대사와 무관한 장면을 연결할 수 있으므로 제외한다.
이번 수동 묶음의 검토한 구간은 소스 SHA-256과 실제 시간 범위, 검토 이미지로
고정하고 모든 발화 구간에 직접 장면 또는 검토한 맥락 장면을 연결한다.
검토 이미지는 해당 작업의 관리되는 미디어 폴더에 보관해 제작실에서도 표시한다.

다운로드 파일은 실제 영상 트랙을 확인한다. 대용량 제한 때문에 음성 파일만
남은 경우 영상 확보로 간주하지 않으며 기존 부분 파일은 진단용으로 보존한다.
삽입 문자의 블러 강도는 캡컷 효과와 별도 MP4 렌더링에 함께 반영한다.
캡컷 창 활성화·프로젝트 확인이 안 되면 다른 창에 입력하지 않고 기존 편집
구성으로 MP4를 내보내며 결과의 내보내기 방식을 명시한다.

## 검색 제한과 요리 보조 장면

브라우저의 인증 상태 확인도 외부 요청으로 취급한다. 기본적으로 인증 확인·검색
페이지 이동·이미지 업로드 사이에 30초 대기를 적용한다. 인증 확인에서 CAPTCHA나
429를 받으면 같은 공급자의 검색 탭을 열지 않는다. 대표 장면의 역이미지 검색은
기본 2장으로 줄이고, 실제 요청 시각과 작업 종류를 검색 감사 기록에 남긴다.
CAPTCHA/429 이후 휴식은 사용자 요청에 따라 최대 10분으로 제한한다. 반복 차단
횟수는 진단용으로 보존하되 휴식을 늘리지 않는다. 기존에 저장된 긴 휴식도 차단
시각부터 10분으로 제한한다. 휴식 만료가 자동 재시도를 등록하지는 않으며, 다시
인증이 요구되면 해당 검색을 멈추고 다른 공급자나 확보한 소스로 진행한다.
쿠키 초기화나 인증 우회는 하지 않으며, 이 간격이 CAPTCHA를 없앤다고 보장하지 않는다.

소스 검색의 긴 지시문을 잘라 검색엔진에 보내지 않는다. 명시적인 짧은 검색어는
줄바꿈 또는 쉼표로 구분한다. 다진 마늘은 일반 요리나 달걀 검색어 대신 실제로
관측한 마늘 준비 동작의 한국어·영어·중국어 구문을 사용한다.

닭고기 손질이나 채소 혼합은 마늘 영상의 일반적인 요리 상황을 설명하는 보조
영상으로 사용할 수 있다. 실제 파일 해시·검토 프레임·사용 제한을 저장하고
`context_only`로 구분한다. 마늘이 들어 있다는 사실이나 마늘 보관·변색·안전성의
증거로 승격하지 않는다. 편집 AI와 저장된 후보 모두 직접 시연(`direct`) 대신
맥락 장면(`context`)으로 제한하며 삽입 문자의 블러 검토는 계속 필요하다.
