# 계정 목록 Git 공유

`influencer_list.txt`가 모니터링 대상과 표시 순서의 기준이다. 웹에서 계정을 추가·삭제하면 이 파일과 로컬 DB를 반영한다. 파일을 커밋·push하고 다른 PC에서 pull한 뒤 계정 목록 새로고침 또는 수집을 실행하면 해당 PC의 DB가 동기화된다. 앱은 Git 명령을 자동 실행하지 않는다. 양쪽 PC에서 같은 파일을 바꿨다면 Git 충돌을 먼저 해결한다.

계정 메모·로그인 세션·게시물·조회수 기록·제작 작업은 각 PC에 유지한다. 목록에서 제거해도 게시물과 이력은 삭제하지 않는다. 제거 전 계정·메모는 Git에서 제외된 `data/account-imports/`에 백업한다. 수집·분석 결과 화면은 다음 분석 때 새 대상 목록을 반영하며, 이미 만들어진 리포트를 소급 수정하지 않는다.

계정 조회와 변경은 SQLite 트랜잭션으로 직렬화한다. 파일은 임시 파일을 완성한 다음 교체하고, 저장 직전 원본이 바뀌었으면 덮어쓰지 않는다. 파일 저장 후 DB 반영이 중단되면 다음 조회에서 파일을 기준으로 복구한다. 파일과 DB를 직접 동시에 편집하지 않는다.

잘못된 계정·UTF-8 오류·Git 충돌 표시가 있으면 기존 DB를 유지하고 API에서 오류를 알린다. 파일이 없으면 기존 DB를 사용하며 다음 웹 변경에서 파일을 다시 만든다. 우연히 비어 버린 파일을 전체 삭제로 해석하지 않는다. 웹에서 마지막 계정을 삭제하면 `# hotpost: empty-list` 표시를 기록한다. 파일로 전체 삭제를 명시하려면 이 표시를 사용한다.

검증: `tests/test_account_git_sync.py`는 두 PC의 독립 DB, 순서 변경, 메모 분리, 과거 게시물 보존, 빈 파일·충돌 보호, 저장 실패·동시 변경과 실제 HTTP API 왕복을 확인한다. 운영 데이터로 테스트 계정을 추가하지 않는다.
