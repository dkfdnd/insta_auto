수집 문제 해결 방법

아래 명령은 Hotpost 서버가 실행되는 PC의 insta_auto 폴더에서, 프로젝트 가상환경을 활성화한 터미널로 실행합니다. 화면 새로고침과 실제 Instagram 수집은 다른 작업입니다.

데이터가 오래됐거나 예약 수집이 누락됐을 때

먼저 현재 수집이 실행 중인지 확인하세요. 실행 중이 아니라면 수동으로 수집하고, 완료 후 메인을 새로고침하세요. 예약 상태는 별도로 확인할 수 있습니다.

python -m hotpost run --no-browser
python -m hotpost schedule status

Instagram 로그인·인증이 필요할 때

아래 명령으로 수집용 전용 Chrome을 열어 로그인·인증을 직접 완료하세요. 터진게시물 페이지를 보는 브라우저의 로그인 상태와는 별개입니다. 인증 완료 후 수집을 다시 실행하세요.

python -m hotpost login --browser dedicated

요청 제한·429가 표시될 때

즉시 재시도하지 말고 서비스에서 제한이 해제될 때까지 기다리세요. 검색은 제한 감지 후 해당 공급자를 30분간 쉬게 하지만, 서비스의 실제 제한은 더 오래 지속될 수 있습니다. CAPTCHA가 나오면 열린 전용 Chrome에서 직접 해결하세요.

계정 페이지를 사용할 수 없을 때

아래 계정 카드의 Instagram 프로필을 열어 아이디 변경·삭제·비공개 여부를 확인하세요. 변경된 아이디는 올바른 계정으로 등록하고, 수집하지 않을 계정은 관리 목록에서 삭제하세요. 과거 수집 이력은 보존됩니다.

서버 연결·상태 조회가 실패할 때
